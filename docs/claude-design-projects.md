# Proyectos relacionados en Claude Design (claude.ai/design)

Prototipos hechos en la herramienta de diseño en la nube de Claude
(`claude.ai/design`), previos o paralelos al código real en `app/`. Requieren
`/design consent` en Claude Code para que un agente pueda leerlos vía MCP.
**No están sincronizados con `app/`** — cada uno tiene su propia lógica,
algunas más completas que otras. Tratarlos como referencia histórica, no
como fuente de verdad.

Cada proyecto guarda su propio historial de chat en el servidor de Claude
Design (independiente de cualquier sesión de Claude Code) — se puede leer
con la herramienta `get_conversation` si hace falta recordar qué se pidió
en cada uno.
